# Linear Algebra for Machine Learning

Linear Algebra is the mathematical foundation of Machine Learning. It helps us represent, transform, and analyze data using numbers, vectors, and matrices.

## Topics Covered

### 1. Scalars
A scalar is a single numerical value.

**ML Use:** Learning rate, bias, loss, and other single values.

### 2. Vectors
A vector is an ordered collection of numbers used to represent a data point or features.

**ML Use:** Feature vectors, embeddings, and image data.

### 3. Matrices
A matrix is a 2D collection of numbers arranged in rows and columns.

**ML Use:** Datasets, weight matrices, covariance matrices, and transformations.

### 4. Matrix Multiplication
Combines matrices to perform transformations.

**ML Use:** Neural networks, Linear Regression, and other ML computations.

### 5. Dot Product
Multiplies corresponding elements of two vectors and adds the results.

**ML Use:** Predictions, similarity, and Neural Networks.

### 6. Cross Product
Produces a vector perpendicular to two 3D vectors.

**ML Use:** Computer Vision, Robotics, and 3D applications.

### 7. Transpose
Changes rows into columns and columns into rows.

**ML Use:** Matrix operations, covariance calculations, and PCA.

### 8. Determinant
A scalar value that describes properties of a square matrix, including whether it is invertible.

**ML Use:** Matrix inversion and mathematical transformations.

### 9. Rank
Represents the number of linearly independent rows or columns.

**ML Use:** Detecting redundant features and dimensionality analysis.

### 10. Inverse
Reverses the transformation performed by a matrix.

**ML Use:** Linear Regression and solving systems of equations.

### 11. Eigenvalues
Represent how much a particular direction is stretched by a transformation.

**ML Use:** PCA and dimensionality reduction.

### 12. Eigenvectors
Represent directions that remain unchanged during a matrix transformation.

**ML Use:** PCA and feature extraction.

### 13. Norms
Measure the magnitude or length of a vector.

**ML Use:** Distance calculations, regularization, and optimization.

### 14. Orthogonality
Two vectors are orthogonal when they are perpendicular and their dot product is zero.

**ML Use:** PCA, feature engineering, and dimensionality reduction.

### 15. Singular Value Decomposition (SVD)
Decomposes a matrix into three matrices:

\[
A = U\Sigma V^T
\]

**ML Use:** PCA, dimensionality reduction, recommendation systems, image compression, and NLP.
